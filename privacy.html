Privacy Policy

Effective September 7, 2026

GIFStar is designed to avoid persistent storage. Submitted files are processed for conversion and are not intentionally saved by GIFStar to a database or object-storage service.

1. Overview

This Privacy Policy explains how GIFStar handles information when you use the application. GIFStar is an open-source Discord utility maintained by Eisenrot.

The application's purpose is narrow: receive an image or short video file you explicitly provide through Discord, convert it into a GIF, and return the resulting file to Discord. Video audio, if present, is not kept in the GIF output.

2. Information GIFStar processes

When you invoke /gifstar, Discord sends an interaction request to GIFStar. Depending on the context, that request can include:

  • the file attachment you explicitly selected, including its Discord-hosted URL, filename, size, and content type;
  • Discord interaction metadata needed to authenticate and answer the request, such as application, interaction, user, channel, or server identifiers;
  • the interaction token used to send the converted file back to Discord;
  • technical request information that may be handled by the hosting infrastructure, such as timestamps, network information, request status, and basic runtime logs.

GIFStar does not ask you to create a separate account and does not request passwords, payment information, address-book data, or Discord message history.

3. How the information is used

The information above is used only as needed to:

  • verify that a request genuinely came from Discord;
  • download and decode the file you chose;
  • convert the image or video into GIF format;
  • respect Discord's attachment-size limit for the interaction;
  • send the converted GIF back to Discord;
  • diagnose operational failures, abuse, and service errors.

4. Storage and retention

GIFStar is intended to be stateless. Submitted files and generated GIFs are processed transiently while handling the request.

  • For image conversion, GIFStar processes the file in memory.
  • For video conversion, GIFStar may create a temporary local file only for the duration of the conversion process and then delete it.
  • GIFStar does not intentionally store submitted files or converted GIFs in a database or long-term object storage.

However, infrastructure providers such as Discord and Vercel may temporarily process, cache, or log technical data as part of delivering the service.

5. Sharing

GIFStar does not sell your data. Information is shared only to the extent necessary for the service to function, including with Discord and Vercel as infrastructure providers.

6. Security

GIFStar uses Discord's signed interaction flow to verify requests. No system can be guaranteed perfectly secure, but reasonable technical measures are used to reduce unnecessary data exposure.

7. Children's privacy

GIFStar is not directed to children under the age required by applicable law and Discord's policies.

8. Changes to this policy

This Privacy Policy may be updated from time to time. The updated version will be posted on this page with a revised effective date.
